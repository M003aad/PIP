# PIP - Picture-in-Picture Chrome Extension
**PIP** Enable Picture-in-Picture (PiP) for any video on the web. Watch videos in a floating window while browsing other sites.

## Features
- Toggle PiP mode for any HTML5 video.
- Works with YouTube, Vimeo, and most video platforms.
- Quick access via toolbar icon.
- Lightweight and easy to use.
- Open Source – Fully open source and available on GitHub for transparency and contributions.
