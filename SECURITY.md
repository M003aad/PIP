# Security Policy

## Supported versions

The project currently supports the following versions:

| Version | Supported |
| --- | --- |
| 1.0.x | ✅ Supported |
| 0.x | ❌ Unsupported |

We recommend updating to the latest supported release as soon as possible.

## Reporting a vulnerability

Please do not open a public GitHub issue for security vulnerabilities.

Use one of the following private reporting channels:

- GitHub Private Vulnerability Reporting: use the "Security" tab on the repository and select "Report a vulnerability"
- Email: 188705139+M003aad@users.noreply.github.com

When reporting, include:

- a concise description of the issue
- affected version(s)
- steps to reproduce the vulnerability
- potential impact
- any suggested fix or mitigation

## Response expectations

We aim to acknowledge reports within 5 business days and provide a status update within 10 business days when the report is triaged.

For valid reports, we aim to:

- assess and confirm the issue promptly
- prepare and validate a patch in a timely manner
- release a fix in the next compatible version when possible

## Disclosure policy

We request that security researchers and users give us a reasonable period to investigate and remediate issues before public disclosure. If a fix is not yet available, we will coordinate responsibly on a private basis.
